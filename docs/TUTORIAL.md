# 教程：从买晶体管到流片你自己的电路

> 适用读者：完全没碰过 TapeOut 的新手（第一部分），以及想直接 REF 调用
> secp256k1 Auth Core 零件的开发者（第三部分起）。
> 全部操作在 BNB Chain 主网；除了明示的链上费用外没有任何隐藏成本。

---

## 第一部分：30 秒理解这个游戏

TapeOut（tapeout.net）把「造芯片」搬上了区块链：

- **晶体管 = 代币**。NAND（与非门）和 LATCH（锁存器）是 ERC-1155 代币，属于某台「处理器」
- **电路 = 资产**。你在画布上把晶体管连成电路，按「TAPE OUT」流片后，代币**真的被烧掉**，电路永久刻在链上
- **REF = 免费引用**。任何人的成品电路都可以当黑盒拖进你的画布——**引用不烧代币、双方都不收费**。你只用为自己的原创门付代币

本教程用的零件来自 **secp256k1 Auth Core**（符号 ECREC）：

- 详情页：https://tapeout.net/#p/0xa3b6d9121146c29fb236001b93a45cb7a78a2247
- 它用 40,496 个晶体管在链上重建了 ecrecover（签名验证），拆成 13 颗可引用的零件

## 第二部分：准备工作（5 分钟）

### 1. 钱包与 BNB

需要 MetaMask（小狐狸）或任意 EVM 钱包，里面有少量 BNB 付费用。

**费用预期（先说好，弹窗不慌）：**

| 操作 | 预期花费 |
|---|---|
| 铸造晶体管 | 0.0001 BNB/个 + 每笔 0.0001 BNB 协议费 |
| 流片一颗小电路 | gas 约 0.0008–0.0015 BNB |
| REF 引用零件 | **0**（不烧代币、不收费） |
| 本教程完整跟练 | **合计约 0.001–0.002 BNB**（≈ 1 美元不到） |

MetaMask 默认的 BSC RPC（如 Infura 无密钥版）会**吞交易**：钱包显示成功、实际从未广播。

设置方法：小狐狸 → 设置 → 网络 → BNB Chain → 把 RPC 改为
`https://bsc-dataseed.binance.org`

### 3. Gas 价格

BSC 上 0.05–0.15 gwei 都能成交。0.15 gwei 实测 10 分钟内确认。

## 第五部分：REF 引用我们的零件（重点）

画布上可以把任何已流片电路拖进来当黑盒。以下是 secp256k1 Auth Core
货架上对第三方最有用的三颗零件。

### 零件速查表

| cid | 名称 | 引脚 | 类型 | 适合 |
|---|---|---|---|---|
| 7 | keccak_comp | 204→64 | 纯组合，无状态 | **新手首选** |
| 1 / 6 | fadd64 | 67→65 | 有状态（4 拍一个运算） | 进阶 |
| 2 | mcore256 | — | 有状态（内嵌 REF→cid1） | 高级 |

### 5.1 新手例：用 cid7 搭「三路异或器」

cid7 是 Keccak 轮函数的核心组件，204 入 64 出，纯组合逻辑（无锁存器），
输入即得输出，不需要任何驱动时序。

**引脚定义：**

| 引脚 | 含义 |
|---|---|
| 0–63 | 操作数 a（64 位） |
| 64–127 | 操作数 b |
| 128–191 | 操作数 c |
| 192–196 | lane 编号（本例全部接 0） |
| 197–201 | 轮次（本例全部接 0） |
| 202–203 | 模式：`01` = XOR3，`00` = χ |

**两种已实测的模式**（链上实时复现 4/4 通过，见 `docs/INDEPENDENT_AUDIT.md`）：

- **模式 01（XOR3）**：`out = a ⊕ b ⊕ c`
- **模式 00（χ）**：`out = a ⊕ (¬b ∧ c)`——Keccak 的非线性层，密码学里很难手写的部分，这里一根 REF 就有了

**操作**：画布上拖入 cid7 黑盒 → 你的输入接到 a/b/c → lane/round 接常量 0
→ 模式脚 202 接 1、203 接 0 → 64 个输出就是结果。
**成本：REF 不烧代币，你只烧自己画的那几个常量门。**

### 5.2 进阶例：REF cid1 fadd64 做 256 位加法

fadd64 是字串行 ALU：256 位运算拆成 4 拍，每拍吃一个 64 位字。

**引脚（67 入 / 65 出）：**

| 引脚 | 含义 |
|---|---|
| 0–63 | in_word，本拍的 64 位字（低位字先走） |
| 64–65 | op：0=LOAD 1=ADD 2=SUB 3=READ |
| 66 | start：4 拍组的首拍置 1 |
| 输出 0–63 | out_word；输出 64 | cout（ADD 溢出 / SUB 借位取反） |

**完整 a+b 流程**：LOAD a（4 拍）→ ADD b（4 拍，和逐拍流出）。
有状态电路的逐拍驱动用见证合约的 `beat()`（每次调用留链上痕迹），
免费预览用 `evaluate()`/`step()`。接口见 `docs/INDEPENDENT_AUDIT.md` 与
`scripts/independent_audit.py` 里的真实调用编码。

### 5.3 懒得画？直接用代码生成网表

```bash
git clone https://github.com/shayuclubguge-cyber/secp256k1-auth-core.git
cd secp256k1-auth-core
python - <<'EOF'
from tapeout import Circuit

# 造一颗「REF cid7 做 XOR3」的电路：核心只有 1 条 REF 指令
c = Circuit("my_xor3", n_in=192, n_out=64)
pins = c.input_signals()
CPU = bytes.fromhex("a3b6d9121146c29fb236001b93a45cb7a78a2247")

# 补齐 cid7 的 204 个输入：a/b/c + lane(0)×5 + round(0)×5 + mode=01
refs = c.ref(CPU, 7, 204, 64,
             pins + [c.zero()] * 10 + [c.one(), c.zero()])
outs = c.seal_outputs(refs)   # 协议要求输出封存在末尾，产生 128 个自有 NAND
open("my_xor3.net", "wb").write(c.to_bytes())
print(f"完成：{len(c.instructions)} 条指令，{c.gate_count()} 个自有 NAND")
EOF
```

实测输出：`129 条指令，128 个自有 NAND`（1,539 字节网表）。
**流片成本 = 只烧你自己的 128 个 NAND（≈ 等值 0.0128 BNB 的代币），REF 部分零消耗。**
生成的 `my_xor3.net` 可以直接拿去流片。

## 第六部分：流片（TAPE OUT）

1. 画布上确认电路行为无误（本地运行免费）
2. 按 **TAPE OUT** → 钱包弹窗 → 确认
3. 你的 NAND/LATCH 被烧掉，电路获得永久 cid，任何人都能 REF 它

**硬限制（BEP-652，2026-04-28 Mendel 硬分叉后）：**
- 单交易 gas 协议上限 16,777,216
- 实测换算：**gas ≈ 421 × 网表字节数 → 单电路 ≤ 约 39 KB**
- 超过就拆：大电路拆成多颗零件、用 REF 缝合（我们的 Keccak 引擎就是这么从 110KB 拆成 5 颗的）

## 第七部分：常见问题

**Q：REF 引用要付钱给零件作者吗？**
不要。REF 零消耗、零费用——已实测确认。零件的价值体现在处理器的采用度上。

**Q：同一个设计能流片两次吗？**
能。同网表重复流片会得到不同 cid 的独立实例（我们货架上 cid 1/6、4/5、9/10 就是同构多实例）。

**Q：晶体管买错了能退吗？**
不能。铸造进钱包可以，烧成电路就永久销毁。先小量试。

**Q：处理器的总量/单价以后会变吗？**
合约没有任何修改经济参数的接口。注意：TapeOut 协议合约目前仍是可升级代理
（官网明示 seal 前所有者保留升级钥匙），「无修改接口」指当前实现层面。

**Q：我怎么确认这些零件没吹牛？**
跑 `python scripts/verify_release.py --chain-only`——20 秒，13 颗电路逐字节比对，不用信任任何人。
